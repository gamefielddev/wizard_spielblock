## 2. Allgemeine Informationen zur Datenverarbeitung

Die App „Wizard Spielblock“ dient als digitaler Mitschreibblock für das physische Kartenspiel Wizard. Sie ermöglicht es, Spieler und Spielstände zu erfassen sowie Spielhistorien und Statistiken einzusehen.

Der Schutz deiner Privatsphäre ist mir wichtig. Die App ist so konzipiert, dass die für den Spielfluss eingegebenen Daten ausschließlich lokal auf dem jeweiligen Gerät gespeichert und verarbeitet werden.

Es gibt keine Benutzerkonten, keine Anmeldung und keine eigene Server-Infrastruktur zur Speicherung oder Verarbeitung deiner Spielinformationen.

Die App ist kostenlos und werbefrei.

## 3. Welche Daten werden verarbeitet?

Bei der Verwendung der App können folgende Informationen eingegeben und verarbeitet werden:
- Spielernamen
- Anzahl der angesagten Stiche
- Anzahl der tatsächlich gemachten Stiche
- Daraus berechnete Punkte und Spielergebnisse
- Spielhistorien und daraus abgeleitete Spielstatistiken

Diese Informationen werden ausschließlich zur Bereitstellung der Spielfunktionen verwendet.

Bitte beachte, dass Spielernamen personenbezogene Daten sein können, sofern sie Rückschlüsse auf eine bestimmte Person ermöglichen. Es empfiehlt sich daher, bei Bedarf Spitznamen statt vollständiger Namen zu verwenden.

## 4. Lokale Speicherung der Daten

Die Speicherung erfolgt über die Funktion „Persisted App State“ von FlutterFlow. Dabei werden die eingegebenen Informationen mithilfe des Shared-Preferences-Pakets lokal auf dem Gerät gespeichert.

Die gespeicherten Spielinformationen werden nicht an mich als App-Entwickler übertragen. Ich habe keinen Zugriff auf die auf deinem Gerät gespeicherten Spielstände.

Die App verwendet nach aktuellem Stand keine eigenen Cloud-Speicher, keine Firebase-Dienste und keine Synchronisierung zwischen verschiedenen Geräten.

Es ist keine gesonderte Datensicherung durch die App implementiert. Abhängig von den Einstellungen und Funktionen des jeweiligen Betriebssystems können lokale App-Daten jedoch gegebenenfalls Bestandteil einer geräteweiten Sicherung sein. Auf solche Sicherungen habe ich keinen Einfluss.

Es erfolgt keine Weitergabe von Spielinformationen zu Werbe-, Marketing- oder Profilingzwecken.
